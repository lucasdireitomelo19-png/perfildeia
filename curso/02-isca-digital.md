Para editar: altere `prompts.json` e rode `python3 curso/isca-50-prompts/build.py` + `node ferramentas/render-pdf.js curso/isca-50-prompts/isca.html curso/isca-50-prompts/50-prompts-que-funcionam.pdf`.

**Formato:** PDF de 15–20 páginas no visual claro da marca (ou página Notion pública).
**Entrega:** ManyChat no Direct (palavra-chave "PROMPTS") + página de captura no link da bio.
**Captura:** nome + e-mail + WhatsApp (opcional). Ferramentas: MailerLite/Brevo (grátis no início).

## Exemplos de prompts (modelo para os 50)
```
[TRABALHO] Você é um especialista em comunicação corporativa.
Reescreva este e-mail para ficar educado, firme e com no máximo 5 linhas.
Objetivo: [OBJETIVO]. E-mail original: [COLE]
```
```
[NEGÓCIO] Você é um copywriter de e-commerce. Escreva 3 versões de descrição
para [PRODUTO], destacando benefícios (não só características), com 1 frase de
impacto, 3 bullets e uma chamada para compra. Público: [PÚBLICO].
```
```
[ESTUDOS] Explique [ASSUNTO] como se eu tivesse 12 anos. Depois me faça
5 perguntas para testar se entendi, uma de cada vez, e corrija minhas respostas.
```
